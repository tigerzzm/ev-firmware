At the table

Before your time slot

  • Car and batteries impounded separately. 8 AA, no lithium, labels readable.
  • The car arms without NOT CALIBRATED: every config.h §1 value is measured.
  • Car ≤ 80.0 cm long with pusher and MP, ≤ 35.0 cm wide. Rear MP is the rearmost point, ≤ 1.0 cm above the floor.
  • USB unplugged. The car may not be tethered.
  • Kit Modification Form impounded, if you started from a kit.
  • Unsharpened #2 pencil, this card, and a pen.

At the table

Firing a run

  1. Power on

    At EV ready, short-press SET. Holding SET for 2 s opens the bench menu instead.

    EV readySET=run hold=cal

  2. Enter the targets

    Turn the dial to change a value, press the dial to change the step, press SET to confirm. Every value starts from what the last run used.

    D
    Target Distance, 5.00–9.00 m
    B
    Bottle Line past the Target, 1.00–3.00 m
    T
    Target Time, 10.0–20.0 s in 0.5 s steps
    Level
    Regional 2.0 m · State 3.0 m · National 4.0 m
    MPofs
    0.000 on run 1 (see Run 2 corrections)
    BtlOfs
    0.000 on run 1
    D:7.00mInc: 0.250

  3. Check the plan

    Forward stop (xF), reverse length (rev) and start delay (dly), in metres and seconds. T SHORT means it will finish late. It still runs; late costs 0.5 pt/s.

    xF 8.50 rev1.50dly 0.0s ok

  4. Place the car

    At ARMED: rear MP over the Start dot within about 1 cm, body on the Target side, aimed down the centerline. Distance and heading are zeroed when you press START, so adjusting now is fine. SET backs out.

    ARMED NO IMU! means the heading sensor isn't answering. The run still works, with the wheels held straight.

    ARMED SET=backD7.00B2.00T15.0

  5. Start

    Tell the event supervisor you're ready. Press START with the pencil, straight down. Only the pencil may touch the car. Run Time starts now, and the LCD counts the start delay down.

    Delay 3.2st 1.8 / 15.0

  6. Hands off

    The car drives, slows for the bottle, pushes it past the line, stops for 0.4 s, reverses, and stops on the Target. Don't follow it; wait until you're called. It stays braked so it can be measured. SET aborts at any time.

  7. Read the result

    Line 1: the encoder's rear-MP error and the run time. Line 2: the forward-stop error. The supervisor's tape is the official result. Write it in the run log.

    MP +0.4cm t15.03F +1.2cm ok

At the table

Run 2 corrections

At the result screen, short-press SET. D, B, T and the level carry over. Change only the two offsets, by the amounts below: the dial starts at what the last run used.

Last run resultChange by
Rear MP 3 cm beyond the Target (bottle side)MPofs − 0.030
Rear MP 2 cm short of the Target (Start side)MPofs + 0.020
Bottle's near side 2 cm short of where you want itBtlOfs + 0.020
Bottle not fully past the lineBtlOfs + the shortfall + 0.020
Example: run 1 used MPofs −0.020 and the MP still ended 1 cm beyond. Enter −0.030, not −0.010.

Each offset moves only its own stop. MPofs never changes the push; BtlOfs never changes where the rear MP ends.

Reference

How the car runs

Every position is the rear MP's distance from the Start, along the centerline. Core 1 tracks position and heading 500 times a second. Core 0 runs the sequence and decides speed and steering every 2 ms.

contact = bottle − bottle radius − L_P       pusher reaches the bottle
xF      = D + B + 5 cm + BtlOfs − L_P       forward stop: bottle's near side 5 cm past the line
xFinal  = D + MPofs                         final stop: rear MP on the Target
delay   = T − estimated driving time        the car waits this long, then drives
StageWhat happensSpeed
STARTRun Time starts. Distance and heading are zeroed.—
DELAYStands still, counting down0
CRUISEDrives toward the bottle on the centerline0.6 m/s, up to 1.6
CAPTUREThe last 15 cm before the bottle and first contact0.2 m/s
PUSHPushes, then eases to a stop at xF so the bottle stays seated0.6 m/s, up to 1.5; ends at 0.06
TURNMotor braked, wheels held still0 for 0.4 s
REVERSEBacks up toward the Target0.35 m/s, up to 0.8; ends at 0.05
STOPBrakes at xFinal and holds, wheels still, until the next run0

Speeds above the first figure are used only when the run would otherwise finish late. Capture speed never changes.

Reference

Every 2 ms

Position

Net encoder distance: forward counts minus backward counts, each with its own scale. It triggers every stage change and both stops.

Speed

Target speed for the stage, with acceleration limits. A feedback loop compares it with the measured speed and sets the motor PWM. A short kick gets the car moving. It never drives against the leg.

Steering

The law chosen in config.h §4 (below). If the heading is lost, the wheels go straight and the car finishes on the encoder.

Checks

SET, the timeout, encoder alive, progress, direction, and heading health (safety table below).
